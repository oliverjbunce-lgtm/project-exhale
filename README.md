# Project Exhale

A new website concept for Project Exhale, built around the creative idea **Pressure → Release**.

## Stack

- Next.js
- React
- Tailwind CSS
- Framer Motion
- Vercel-ready

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Current build

The first homepage concept includes:

- Pressure → Release hero experience
- Dark editorial visual system
- Project Exhale framework
- Organisational services
- Founder story
- Contact CTA
- Responsive mobile treatment

Current Jo photography is referenced from the existing Squarespace CDN while the new art-directed image set is being developed.
